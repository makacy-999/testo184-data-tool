工作流程

四步完成一次批量读取

一台一台插，一台一台读。每读完一台系统会提示更换下一台，全部读完自动汇总。

配置测点

输入本次要监测的测点数量，生成测点清单，测点编号可自行修改。

例如：1 号冷库、2 号冷库

读取设备 / 软件联动

USB 插入温度计自动识别解析（图形报告曲线还原 + .xdp 数据包直读）；上传 .vi2 / .xml / .xdp / PDF 一键导入（支持多选）；或开启联动模式，监控 Testo 软件导出文件夹，新数据文件自动导入。

曲线图也能逆向还原成数据表

核对汇总

所有设备读取完毕，核对测点—SN 对照表与数据条数，发现误读可单独重读。

数据同时存入本机数据库，可回看历史

导出 Excel

一键生成汇总工作簿：全部数据 + 每台设备独立工作表 + 统计摘要。

文件名自动带时间戳

列：测点号、设备 SN、序号、日期、时间、温度、湿度、报警。跨测点筛选、透视都在这一张表完成。

快速开始

两种运行方式，选一种即可

方式一 · 下载可执行文件（推荐）

适合非技术同事，无需安装任何环境。

常见问题

使用前值得知道的几件事

数据存哪里？会上传吗？
全部保存在你电脑上的本地数据库（程序目录的 data 子目录），不经过任何服务器。导出的 Excel 也只生成在本机，由你自己分发。
支持哪些型号？可以同时插多台吗？
当前版本针对 Testo 184 系列设计。读取方式为逐台插入：插一台读一台，读完提示更换下一台——这样测点与设备 SN 的对应关系最可靠，也避免 USB Hub 供电不足导致读数失败。
温度计读不到数据？用软件联动自动转 Excel。
部分 Testo 184 固件的完整数据需官方软件读取。推荐「软件联动」：① 建一个空文件夹（如桌面「testo导出」），把路径填到工具的联动模式里点「开始监控」；② 点「一键调用 Testo 软件」自动打开电脑上的 ComSoft/Testo 软件（或手动打开），插上温度计，在软件里读取并保存 .vi2 / .xml / .xdp 到该文件夹（保存了其他格式文件时页面会提示文件名和原因）；③ 本工具检测到新文件即自动解析导入（自动识别 SN、采样间隔、起止时间），多台依次保存即可，最后导出 Excel。把温度计 U 盘里的 testo 184 measurement report（图形报告）或 configuration_数据.xdp 拖到「直接导入数据文件」处即可读取——图形报告会自动从曲线还原数据；也支持一次多选多个文件手动导入。扫描设备时页面会显示每个文件的处理明细（格式、解析条数、原因），数据读不出时可直接定位问题文件。
识别不到温度计怎么办？
点击「扫描 USB 设备」前先确认设备指示灯亮起；macOS 如仍无法识别，换个 USB 口或转接头再扫。接入后系统会把设备识别为一个 U 盘形状的存储设备。
读错了能重读吗？历史能找回吗？
可以。读取确认前可放弃重插；确认后发现错误，可在会话中删除该测点重读。所有历史会话保存在本机数据库，打开应用即可切换查看。
是开源的吗？
是，采用 MIT 协议开源，源码与更新发布在 GitHub 仓库。
