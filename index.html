快速开始

两种运行方式，选一种即可

方式一 · 下载可执行文件（推荐）

适合非技术同事，无需安装任何环境。解压后只有一个 .exe，双击即可使用。

  1. 在页首点击「下载 Windows 版」，解压后双击运行即可；
  2. 工具会自动在桌面创建快捷方式，并设为开机自启；
  3. 自动打开浏览器进入 http://localhost:8000 使用；
  4. 之后每次开机自动后台运行，直接打开该网页即可，无需再手动启动。

方式二 · 源码运行

适合需要查看或修改代码的场景。

首次运行自动创建虚拟环境并安装依赖，之后打开 http://localhost:8000。

常见问题

使用前值得知道的几件事

为什么我下次直接打开网页就能用？
首次双击运行时，工具会自动在你的桌面创建快捷方式，并注册为开机自启。之后每次开机它都在后台自动运行（不弹窗、不干扰），你只需在浏览器打开 http://localhost:8000 就能直接使用，无需再手动启动。若想彻底停用自启，在桌面图标右键 → 打开所在位置删除，再到「任务管理器 → 启动」里禁用该项即可。
数据存哪里？会上传吗？
全部保存在你电脑上的本地数据库（程序目录的 data 子目录），不经过任何服务器。导出的 Excel 也只生成在本机，由你自己分发。
支持哪些型号？可以同时插多台吗？
当前版本针对 Testo 184 系列设计。读取方式为逐台插入：插一台读一台，读完提示更换下一台——这样测点与设备 SN 的对应关系最可靠，也避免 USB Hub 供电不足导致读数失败。
温度计读不到数据？用软件联动自动转 Excel。
部分 Testo 184 固件的完整数据需官方软件读取。工具已内置全自动采集：点「开始批量读取」（若尚未设置，首次先点「⚙ 设置 Comfort Software 路径」选择电脑上的 cc4.exe），工具便在内置后台自动驱动 Testo ComSoft 接力导出 .vi2；此后你只需依次插拔每一台温度计，工具每隔几秒自动扫描接力文件夹，把新导出的测点自动读入（自动识别 SN、极限值、采样间隔、起止时间），无需任何手动操作。插完所有温度计，点「进入下一环节 → 分析导出」即可得到 Excel。也可直接把温度计 U 盘或本机的 .vi2 文件批量上传导入；导出时每个测点独立一张「测点N」表，表头自动带设备概况与极限值。
识别不到温度计怎么办？
点击「扫描 USB 设备」前先确认设备指示灯亮起；如仍无法识别，换个 USB 口或转接头再扫。接入后系统会把设备识别为一个移动磁盘。
读错了能重读吗？历史能找回吗？
可以。读取确认前可放弃重插；确认后发现错误，可在会话中删除该测点重读。所有历史会话保存在本机数据库，打开应用即可切换查看。
是开源的吗？
是，采用 MIT 协议开源，源码与更新发布在 GitHub 仓库。
